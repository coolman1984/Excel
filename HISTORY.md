# History

## 2026-11-14

- **AI may see everything (owner's decision):** AI may read all the data, cell values included. ExcelApp now gives AI agents direct read-only access: `ExcelApp.exe --mcp` (an MCP server for Claude Desktop, Claude Code and other AI apps) and `--query "SELECT ..."`, with a SQL dialect (joins, filters, LIKE, IN, BETWEEN, GROUP BY, HAVING, ORDER BY, LIMIT) translated to the Data engine. Tested with the official MCP client on made-up 3M x 300 data: answers in 0.1 to 1.5 s, 860 MB peak. `SELECT *` reads its 300 columns only for the rows it returns, and a long-running reader sees new versions loaded by the app at once. See `docs\AI-ACCESS.md`.
- **Scale, measured on made-up 1,000,000 x 300 data (`docs\DECISION-5-SCALE-AND-EXCEL365.md`):** the editor opens the fast copy in 0.1 s, jumps anywhere in under 1 ms, filters in 0.3 to 0.7 s, sorts in 0.4 to 2.2 s and searches all 300 million cells in 1.9 s, all under half a gigabyte of memory. The first open of a new file still waits for Excel (rule 0).
- **Out of memory, fixed:** every Data question loaded every column of every period. A sum by region over a 3-month report of 1M x 300 per month ran out of memory on 15 GB. Questions now read only the columns they use (1.5 s, 437 MB). Report unions keep text dictionary-coded, and only the last 4 unions stay in memory. New offline `scale` suite.
- **Owner decisions written down:** how AI may read the data without breaking rule 0, the dashboard designer, and the order of the missing Excel 365 features.

## 2026-11-13

- **Formulas calculate in the editor:** typed formulas show their results, recalculated on every edit, with about 170 functions; fill and paste move relative references.
- **Finished and fixed:** the remaining Excel shortcuts work (Ctrl+D/R, Ctrl+; and Ctrl+Shift+;, Alt+=, Ctrl+Space/Shift+Space, Ctrl+Shift+number formats) and Ctrl+1 opens a new Format Cells dialog. Fixed: the fill handle repeated a value ("item-1, item-2" gave "item-2"); formulas with a left-out argument (=IF(A1,,1)) were refused; XLOOKUP's binary modes returned #VALUE!; a damaged stored table gave a raw error instead of a plain sentence; the Data pages squeezed their top bar on long pages and showed raw ISO times. The Data mode now loads when first opened.
- **Checked on a Linux build machine without Excel or Windows:** every project compiles; the offline formula, fill, edit, filter, store, query and automation suites pass (364 checks); the interface passes its typecheck, 52 unit tests, the build and a browser walk-through of the new shortcuts and the Data pages. Still to run on the laptop: `check.ps1` live (host, save, style and journal suites, and the live Excel formula comparison).

## 2026-11-04

- **First thinking:** measured Excel COM on protected files. Reading one screen takes about 2 ms at any size; opening is the slow part. Rust cannot link on this PC, and C# builds with nothing to install. See `docs\DECISION-1.md`.
- **Cache design:** one column format in memory and on disk, a reader that exists only while needed, and a disk switch off by default. Everything Excel saves here gets the NASCA mark, including CSV; files written by other programs do not. See `docs\DECISION-2-CACHE.md`.
- **Approval:** the owner, acting as IT manager, approved the disk copy for this laptop's local disk only.
- **Real-file test:** reopening a large protected file from the copy took a fraction of a second instead of minutes. The figures stay in private notes on this PC.
- **The viewer:** built `ExcelViewer` in C# Windows Forms: open, scroll, search, sort, and switch sheets.
- **Dates and money:** the copy stores each column's number format, and our display is checked against Excel's own text while the copy is made. Month and day names come from Excel, because Windows and Excel can differ (Sept and Sep). A format that does not match is marked ⚠ and never guessed.
- **Memory stop:** the owner set the stop at 96% Windows commit, one setting in `Machine.StopAt`. The older speed tools in `tools` still use their own lower limits.
- **Lessons from the real file:** sheets can hide zeros, Excel drops the minus when a negative rounds to zero, and Excel gives blank text for cells in hidden columns. All three are handled and tested on made-up data.
- **A hang, fixed:** an old copy with the same version mark failed to load and a hidden error box waited for 19 minutes. The version mark now changes with the layout, a damaged copy is read again, and unattended runs never show a box.
- **Copy:** the owner approved copying for their work on this laptop. Ctrl+C and right-click Copy give the shown text with number formats, tab-separated. The clipboard data asks Windows to leave it out of clipboard history and cloud sync. Both saved copies stay, and hidden rows and columns stay shown, by the owner's decision.
